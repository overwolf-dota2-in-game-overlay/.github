## Troubleshooting Common Issues

Install issues? Run the installer as administrator and allow the client through antivirus and firewall rules.  
Performance problems? Disable unused apps and overlays, then cap the overlay refresh rate in settings.  
License/activation? Sign in again and re-authorise the app if game data stops updating after a patch.  
Compatibility? Update the client when Dota 2 changes break overlay hooks.  
Update failures? Restart both the game and the client, since hooks attach only at launch.
